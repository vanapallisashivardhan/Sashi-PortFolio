# Vanapalli Sashi Vardhan — Portfolio

A responsive gradient-themed portfolio built using HTML and CSS.

## Run locally
1. Extract the ZIP archive.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.

## Included assets
- `assets/profile.png` — uploaded profile photograph
- `assets/resume.pdf` — uploaded resume PDF

## Before publishing
- Confirm the CGPA shown in the Education section. The supplied details say 9, while the resume/achievement details state 8.88. The page currently uses 8.88 and flags it for confirmation.
- Check internship dates and certification titles against the official certificates.
- Add project GitHub or live demo URLs if available.
- Confirm whether the graduation year should be 2028.

## Files
- `index.html` — portfolio content and sections
- `style.css` — gradient design, layout, responsive styling and effects
- `assets/` — profile photograph and resume

No JavaScript or frontend framework is required.
